# Independently implemented terminal game cores

Status: independent rule implementations informed by RECOVERED static declarations. No original runtime behavior was measured; this package alone does not complete B06 or native game qualification. Typespeed is excluded from `TerminalKind::ALL` because the exact original DFM declares `Visible=false`.

## Evidence actually used

Read the reviewed original-static-recovery `README.md`, `catalog.json`, `controls.json`, `sources.json`, and `review.md`, plus B06 in `docs/superpowers/plans/2026-11-23-08-services-platform.md`. Those files identify the seven visible terminal declarations and exact help strings/byte offsets. No companion binary, original executable, original C engine, sprite or artwork was executed, linked, copied into this package, or redistributed. No additional historical source claim is made. All Rust logic and scenes were written independently for this component.

- **Soliterm:** original help at 0x66d4–0x6768 declares mouse source/destination, arrows/Space; 0x69b9–0x6a6c declares Freecell/Klondike and pass count. These do not establish exact legal moves/defaults. Independent conventional Freecell implements 52-card deal to eight columns, four reserve cells, alternating descending tableau, ascending suit foundations, and empty-space sequence capacity. Independent Klondike implements seven columns with hidden cards, King-only empty columns, draw-one stock, bounded passes (1–20), reverse-order recycle, and exposed-card flip. Default Freecell and three passes are product choices. No stalemate detector, hints, original deal-number mapping, draw-three variant or measured score parity.
- **Termwalk:** original help 0x3ed4 declares connecting every server to central router; 0x3f9d/0x3fec declares odd grid size. Independent nonwrapping spanning-tree boards support odd sizes 3–15, default 5, clockwise/counterclockwise tile rotation and connectivity. The generator does not copy an original board; original generation algorithm, wrapping/default size, exact keyboard bindings and solve-grid UI remain unmeasured.
- **Ctris:** exact companion strings establish v0.42, Jul 25 2007, counterclockwise/old-style command options and P resume only. Independent conventional seven tetrominoes, 10×20 field, rotation in 3×3/4×4 boxes, O invariant, no wall kicks, movement, one-step gravity, hard drop, row clears, scoring 100/300/500/800 and spawn-block loss. Piece distribution, score, dimensions, timing, wall kicks, key maps and original old-style behavior are independent choices, not recovered parity.
- **Sudoku:** exact help 0x6486–0x64b2 establishes 9×9 rows, columns, 3×3 boxes, digits 1–9; 0x64e0/0x64f1/0x6553 establish digit/erase/undo. The core independently generates valid Sudoku solutions, removes clues only if a bounded solver certifies uniqueness, fixes starting clues, rejects conflicts and detects completion. Exact historical puzzle generator/difficulty, fix-squares semantics, hints, solve/save/clear-board functions are not asserted or implemented by this core. Clear an editable digit with zero; reset restores initial board.
- **Nimesweeper:** exact help 0x57c4–0x58f4 declares four presets: 16×16/40, 16×24/75 (help-default easy), 30×16/99, 38×20/160. Core preserves those ordered dimensions. Help/disassembly establishes arrows/F/Space/P and restart. Independent conventional reveal/flag/number flood/chord and all-safe-cells victory are implemented. First reveal is safe through deterministic mine relocation (independent choice). Original first-click policy, actual menu override, chord behavior, score/times and exact generation are unmeasured. Wrong chord flags can detonate mines.
- **nInvaders:** exact strings establish Space start and skill command options only. Core independently implements a 32×24 logical shooter with 24 enemies, deterministic horizontal movement/descent, player/enemy projectiles, three lives, per-hit score and win/ground-contact/death outcomes. Conventional left/right/fire/P controls are supplied explicitly. Original shields, waves, art, projectile/formation timings, skill curve, score, UFO and collision details are unmeasured and not represented as parity. This core implements one finite playable wave; original skill options are not exposed.
- **Greed:** original help establishes the first adjacent digit determines the complete move distance, all traversed squares erase, erased squares/out-of-bounds are illegal, and no legal direction ends the game. Those rules are directly implemented with eight directions and legal-direction highlighting. Board dimensions 20×10, seeded digit distribution, starting cell and clear-all win label are independent choices. No original board/score sequence parity is claimed.

## Contract and bounded work

No dependencies, unsafe, filesystem/network/process operations, wall clock, thread, or UI calls. Seeded SplitMix64 shuffles support deterministic new/reset/replay; seed zero is valid. APIs use row-major integer cell indices and small signed deltas. While active, invalid/unsupported inputs return an error atomically at the session boundary. Paused Ctris, Nimesweeper and started nInvaders ignore ordinary gameplay inputs before validating them, returning `Ok(false)` without changing state or history; pause/unpause and nInvaders start remain lifecycle inputs. Completed games require undo/reset. Successful state changes save at most 128 complete states; no-op input consumes no history. RNG, mine relocation, pause and outcome state undo together.

Card state has exactly 52 cards; grids have at most 760 cells (mines) / 225 (Termwalk). Termwalk DFS adds/removes each cell at most once; connectivity visits once. Sudoku attempts at most 81 clue removals, keeps at least 39 clues, with at most 50,000 recursive nodes per attempt and depth at most 81; exhaustion conservatively retains the clue. Mines flood work is bounded by cell/neighbour edges. Ctris is 200 settled cells and each hard drop traverses at most 20 rows. Shooter has at most 24 enemies, 4 player shots, 8 enemy shots. One `Tick` is one simulation step, never elapsed-time catch-up.

Public scenes expose owned integer data, no drawable original assets. `Piece::cells()` saturates offsets at i32 coordinate bounds for arbitrary public values; out-of-board saturation may merge cells, while session-generated board coordinates remain exact. nInvaders exposes `player_y` from the same row constant used for shot origin, enemy-shot collisions and enemy ground contact. See API.md for integration details and the component tests for conventional-rule fixtures. Fixture expectations are never labelled original-observed or MEASURED.
