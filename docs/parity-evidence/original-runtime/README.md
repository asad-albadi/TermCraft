## Final bounded runtime constraint and cleanup

Wine11.22 intermittently reaches the first main screen but is not a reliable original UI fixture here. Xvfb without a window manager remained on a visible startup splash `Creating bookmarks menus (100%)` after80s. A privately extracted, detached-signature-verified official Arch twm1.0.13.1 package (100,976 bytes, SHA-256 `3fdf26ad652031e3129aed3d2da5ded08d26d8c7cbb79cf937edf748c954136e`, Andreas Radke signer matching Xvfb) did not resolve startup. Final Xvfb+twm and Cage runs logged Wine `RtlpWaitForCriticalSection` timeouts in `ntdll/loader.c: loader_section`, waiting threads blocked by another original process thread. These are concrete compatibility constraints, not proof original product functionality is absent. The attempted official stable-Wine archive index request timed out after20s with zero bytes; no alternate runtime was obtained.

A small independent read-only helper built with the staged Wine headers/import libraries and host gcc, without an SDK/install, successfully enumerated Win32 windows in the same private prefix. `win32-menu-query.log` records TMobaXtermForm, TFormParams and TFormSessionEdit HWNDs; the main window was invisible during that run and yielded no native HMENU. This neither proves an empty Games menu nor a scope exclusion. The helper did not send input or accept dialogs.

No actual Games popup, screensaver settings, complete Personal preferences, saved-session/macro exports, limits or package install resolution was measured. Early files called games-menu/settings-menu in the private reports are unsuccessful input attempts during splash or blocked XTEST, explicitly excluded from the evidence handoff. No code or completion count changes are justified by those attempts.

All owned Wine servers/processes, Xvfb, Cage, twm, private GPG agent/scdaemon and command sessions were reaped before handoff. No detached watcher remains. `handoff-manifest.json` lists retained evidence hashes and private stage locations; downloaded runtime binaries and original companion payloads stay in the private target stage and are not added to product packaging.
