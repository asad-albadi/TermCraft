# D01 embedded RDP implementation evidence checkpoint

2026-11-24, Linux. No full original/native parity claim.

The workspace owns a headless RDP helper through private stdin/stdout pipes. It never launches an external desktop window. The helper is a separately locked package (`engines/rdp/Cargo.lock`), avoiding incompatible prerelease cryptography requirements in the RDP and SSH dependency graphs. Client engine: IronRDP connector 0.12.0, session 0.13.0, PDU/graphics 0.11.0 and Tokio adapter 0.12.0. The separately locked owned server fixture uses the published 0.17 meta package. Both use real RDP/TLS/NLA; neither injects fake framebuffer events into the product.

- Planned API/schema absence: `red.log`.
- `final-full.log`: nine real transport cases plus the reviewed UI and input-queue cases. Exact red pixels; target certificate validation and changed remembered certificate requiring a decision before credentials; natural server observation of active TLS closure and reaped helper; canceled certificate prompt; software cursor, key/button focus release; wheel input; server resize/reactivation.
- Reproducing RED logs: cursor, held mouse button on focus loss, release before authentication, server resize and missing wheel API. Cursor fixture expectations allow the library's one-bit premultiplied rounding; the known rectangle still requires exact `[255,0,0,255]`.
- `ui-green.log`: real workspace launch, clicked trust/sign-in controls, actual texture upload, application-window resize with letterboxing, translated pointer/scancode/Unicode/wheel events observed by the server, remembered certificate and no password in workspace JSON. It asserts no external launch/PTY is created. Headless egui painting is not native GPU/window-manager validation.
- `private-secret-api-green.log`: public authentication input now uses non-Debug/non-Serialize `Secret`. Only the private pipe encoder serializes temporary wire values; prompt/IPC buffers are zeroizing. Third-party NLA internals are process-local and are not claimed to wipe every temporary credential copy. No passwords are passed through argv, environment variables, ordinary settings, logs or exported profiles.

Network setup/reactivation and output have deadlines; interactive decisions wait outside network budgets. Input/control queues are bounded; complete frames and cursor notifications coalesce; dimensions are capped at 8192 per axis and 16 Mi pixels, with validated payload lengths. Close has an independent cancellation flag and kills/reaps only its owned helper, regardless of queue state. Unix CA-file opens are nonblocking before regular-file checks. Windows helper launch uses no-console creation flags; native behavior remains pending.

Current foundation uses lossless bitmap graphics, verified TLS and NTLM NLA. Public-CA verification uses the platform verifier; explicit pins remain endpoint-bound and TLS signatures are still verified. Unknown/changed certificates require an explicit decision; reconnect rechecks the exact approved certificate before sign-in. Kerberos network exchange, explicit redirection authorization and richer RDP options/channels belong to D02; unavailable provider capabilities remain gaps rather than enabled checkboxes. Native Windows/macOS, Windows RDP servers, broad codec/endpoint behavior and exact Personal 26.6 comparison are pending. Slow-path input fallback compiles but has no distinct native-endpoint transport evidence yet.

Build/run: `scripts/run-dev.sh`; release build/copy: `scripts/build-release.sh`. Both packages must accompany a release. Fixture/engine test builders use independently locked manifests and cached dependencies. Final gate: `CARGO_BUILD_JOBS=2 cargo test --offline` passed **373 top-level tests, 6 ignored**, plus one isolated source-only helper test (374 raw log-counted passes). Root/helper formatting and shell syntax checks passed. `windows-parent-source-check.log` passes for the source-only parent composition targeting x86_64-pc-windows-msvc; this is not a full Windows app/helper build or native runtime proof. See `review.md` for the independent review and its single RED→GREEN fix pass.
