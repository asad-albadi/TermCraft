## Isolation and limitations

Bubblewrap unshares PID and network, hides host /home and /run, mounts isolated /tmp and minimal /dev (no dri/input/snd), exposes only application source/cache read-only plus this private report subtree writable. HOME/config/data/runtime/private bus are private. Host DISPLAY/Wayland/socket/Xauthority/Sway/bus/PipeWire variables were cleared. Reports/isolation.json proves separate network namespace and no inherited display. No host portal, compositor, input, clipboard, home, or network was accessed; no package installation or host service activation occurred. Private session autoactivation produced expected document-FUSE/accessibility warnings because device/system journal are absent, and PipeWire/WirePlumber logged absent system bus/device monitors; actual video streamed successfully.

This is a configured local Linux pixman headless compositor; it does not qualify a physical GPU desktop, real system consent UI clicks, full application GUI sharing controls, a newly built release binary, Linux RemoteDesktop input, Windows, or macOS. No product defect requiring a source change was demonstrated.
