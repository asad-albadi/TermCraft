## Typed UI contract and common controls

Existing `PuzzleSession::new(PuzzleKind, seed)`, `new_map(seed, MapPreset)`, `input`/`apply`, `undo`, `reset`, `scene`, `outcome`, `kind`, `seed`, `can_undo`, plus `PuzzleKind::ALL`, `selector` and default `help` remain. New `new_config(seed, PuzzleConfig) -> Result<_, &'static str>` validates before allocation/generation; `configuration()` and session `help()` describe the selected rules. `PuzzleKind::presets()` supplies the exact historical stock definitions, including both conditional Map orientations and larger non-small-screen entries: **51 selectable source-defined entries**. The final15 advanced entries return an exact-grade board or explicit bounded exhaustion. `configuration: None` remains reserved for future unavailable entries.

`redo()`/`can_redo()` restore undone states; only a changed branch discards redo, while invalid/no-op/highlight input preserves it. Combined undo/redo snapshots are bounded to 256. `solve() -> Result<bool, &'static str>` is explicit, deterministic and atomic/undoable, and restores the known generated answer (Guess instead gives up). Net also locks every solved tile, matching the source auxiliary-answer Solve; the same atomic snapshot restores the player’s earlier lock vector on undo and all solved locks on redo. `assisted()` follows the state through undo/redo and clears on reset. Mines Solve exposes a hidden layout only after explicit invocation, including after death. Reset restores the captured initial configuration/seed state, recentres Net highlight, and clears history, assistance and deaths. It does not regenerate another configuration.

`NetScene` adds wrapping and per-cell barrier masks (same N=1/E=2/S=4/W=8 representation as ports). `MinesScene` adds generation/solvable metadata and a layout `solution: Option<Vec<bool>>` that is `None` until explicit Solve. A UI can overlay correction marks on the preserved post-death cells using that layout. `SoloScene` adds box dimensions, diagonal/symmetry settings and the constructor logical certificate. Its pencil masks are now `u32`. Guess scene current/held/row pegs/terminal solution are vectors, retaining default lengths four and supporting Super length five. `MapScene` adds its typed configuration; generation/certificate remain exposed. These are source-compatible for dimension/iterator-based rendering, but fixed-array type annotations and fixed-size UI controls need adaptation.

Only typed scenes expose public board data. Net/Map/Solo/Untangle hidden answers remain internal; Guess reveals only at terminal outcome; Mines reveals its layout only on explicit Solve. Constructor certificates describe the initial puzzle, not a proof of arbitrary later user digits. Invalid public session input restores the full prior state and adds no history. All dimensions/counts have explicit caps; every search/generation/graph/flood/history path has a finite bound.

## Verification and retained gaps

The reviewed options round-0 handoff includes 48 component tests, whole-suite Linux verification, strict Clippy, formatting, Windows x86_64 MSVC and macOS aarch64 compile checks. FIX1 adds two public default/configured Net Solve-lock regressions (50 compiled tests total); its targeted checks cover Solve, Net and redo without repeating the broad 288-scene sampler. See the FIX1 report for actual amended-check results; see scoped `puzzle-options` evidence for actual final commands/results. Compilation does not establish native GUI execution or packaging. Eleven restored controlled mutations produce behavioral assertion failures across symmetry, logical grade, wrap/barriers/loop rules, redo, assistance, Guess blank/distinct rules, Mines corrections and point counts. Baseline default Solo rotational/logical failures and new Net fixed-fraction failures are separately captured. Tests sample eight seeds for each selectable stock setting and report actual fallback/exhaustion, rather than asserting all layouts match upstream.

**Still pending:** arbitrary custom Map dimensions/region counts; custom Net dimensions 1/2 or over 16 and sub-percent probabilities; larger custom bounds outside those documented; source-complete Untangle graph generation; separate hint commands; original generator IDs, saved-game import/export and verified interoperability; configuration menus/dynamic controls/redo/Solve/correction rendering in native UI; native platform/package/original-runtime parity. All 51 recovered stock entries are represented; the advanced amendment enables the final 15 with exact logical certificates or explicit bounded generation errors. This options component is an extension to the accepted restricted cores, **not full B06 completion**.


## Advanced source-preset amendment

This amendment is based exclusively on accepted FIX1 payload SHA-256 `f9923a046d53cbac31f08841a5a6dbbb705dc69c49b63cdca32d1f0dde386ef9`, frozen before edits. It adds the remaining nine Solo and six Map stock settings. See `provenance/advanced-source-manifest.json` and `advanced-source-excerpts.txt`, verified byte-for-byte against exact primary Git revision f306b9db55453f7d7fc824bbbf89ca6ac7d2d273. The retained MIT-style `UPSTREAM-LICENCE` applies to source-derived algorithms and excerpted code; copyright Simon Tatham and named contributors. `solo_advanced.rs` and the Map forcing-chain implementation express those source deduction rules in safe Rust. No C code, original executable/art, external process or original runtime oracle is used by the puzzle component.

Solo Intermediate uses row/column/diagonal versus region intersections. Advanced adds general Hall subsets (source zero-rectangle sets, with complementary hidden subsets). Extreme adds single-digit row/column sets (fish) and source bivalue peer-chain BFS. Unreasonable permits bounded recursive search only after Extreme stalls and accepts exactly one solution. Advanced normal grades are limited to9×9; every accepted board is solved by its requested grade and rejected if a lower grade completes it. This amendment never replaces an advanced request with an easier certificate. The pre-existing Trivial/Basic generation and openly disclosed Basic easier fallback remain unchanged.

`SoloVariantConfig { base, jigsaw, killer }` preserves existing `SoloConfig` literals. Jigsaw partitions are independently generated by equal-digit boundary exchanges preserving nine connected nine-cell regions and a valid solution; this is a restricted independent distribution, not upstream divvy_rectangle output or seed compatibility. Clue removal honours the configured symmetry. Killer has no starting digit clues, all cages are connected and contain2–4 cells, repeated cage digits are forbidden, and sums must match. Independent small-cage generation merges away every singleton before certification. The Killer solver includes source cage single, min/max, distinct2/3/4-number sum-set and45-minus-whole-cages residual/split reasoning at normal DIFF_BLOCK and killer DIFF_KINTERSECT. It never calls ordinary Basic numeric/row singles for the Killer stock certificate. A separate lower-KSUMS replay must stall, proving the exact source KINTERSECT requirement; `killer_intersection_required` exposes this condition. Sum masks are precomputed once inside the component.

Map Hard uses source graph BFS forcing chains after Easy and Normal deductions stall. Unreasonable counts solutions to two after Hard stalls; exactly one is required. All six previously disabled Map dimensions/orientations now expose those grades. Every generated advanced Map has a complete exact-grade certificate or constructor exhaustion; no easier fallback is used for either advanced Map grade. Existing default Normal/Easy certified fallback semantics are preserved.

Bounds: Solo full-grid randomized search30,000 nodes per attempt;32 candidates for Intermediate/Advanced/Jigsaw,96 for Extreme/Unreasonable,256 for Killer;2,000 possible region exchanges per Jigsaw attempt;81 cell removals per candidate, grouped atomically by symmetry; at most810 monotone deduction iterations per9×9 replay; recursive certificate search100,000 nodes per replay. Map retains16 candidate attempts,10,000-node initial colouring searches and uses50,000-node recursive certificate searches per replay. Search-budget exhaustion never supplies a certificate. These finite limits can reject valid user seeds; error text explicitly says budget exhausted. No original seed, saved-game, encoded parameter or game-ID compatibility is claimed.

Renderer contract: `SoloScene.regions` supplies one canonical region id per cell, including ordinary boxes; compare neighbours for thick boundaries. `SoloScene.cages` exposes sorted cage cell indices and `sum: u16`; draw cage outlines and display the sum at its smallest cell. Long-diagonal flag, pencil masks and all existing input/session semantics are preserved. New certificate counters report intersections, sets, Extreme eliminations, recursive nodes and cage deductions; Map reports achieved grade, forcing eliminations and recursive nodes. Rendering/native UI integration is a separate follow-on review. This amendment does not establish full B06 native/original-runtime parity.
