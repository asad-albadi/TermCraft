## Spec and quality/security assessment

The manual typed DTOs cover all13games and all native constructors/configuration fields, including default/configured distinction, Solitaire passes/variant, terminal Mines preset, Termwalk size, both Map orientations, SoloVariant and all PuzzleConfig alternatives. New-map metadata reproduces its existing native configured constructor. Solitaire metadata clamps passes identically to the native constructor. No file API, process handles, UI credentials or executable import inputs are present.

Load checks byte and nesting limits before deserialization, typed schema/version/automatic exact engine identity before replay, then configuration, operands, action count, expanded ticks and replay work before origin.start constructs the candidate. Serde unknown fields/opcodes and unsupported versions reject. Action-count checking follows the operand scan, but input bytes already cap this work/allocation; it remains before candidate construction. The original session and source bytes cannot be mutated by this associated decode API.

Engine identity hashes exact compile-time include_bytes content with path and NUL delimiters for19sources: all16core sources plus library/mod/persistence, cached by OnceLock. Self-source inclusion is deterministic and has no hash-constant cycle. Unknown identity rejects before candidate construction. Full private-state integrity streams derived Debug representations through SHA256 rather than allocating a complete state string. All Core/Session/State and nested structures use complete derived Debug; initial state, hidden answers/layout/RNG, all bounded undo/future entries, assistance, deaths and Net source are included. Integrity is corruption checking, not authentication, as documented. Exact engine identity protects format changes to those Debug representations within this deployment model.

The journal wrapper calls the original action once and preserves its native result; only true/Ok(true) records. Native apply restores state on errors and detects full-state equality on no-ops. Net highlight source changes are meaningful successful operations and are recorded, despite not consuming native undo slots. Undo/Redo/Solve hooks record the native successes, so deaths/assistance/future branches are replayed, rather than synthesized from visible scenes. Reset restores native initial state and starts a fresh journal. No state-hash computation was added to each input hook: additional per-input work is a bounded vector append or tick-run increment; engine/state hashing occurs on save/load. Existing native core histories remain bounded256/128.

Timer ticks are compressed only when consecutive and successful; pause/loss/no-op timer attempts do not expand the journal. Each imported compressed tick is still executed and must succeed. 32768expanded-step and4096entry quotas intentionally bound saveability, without stopping gameplay; Reset clears this limit. Worker timing experiment reran in the independent14test gate: Ctris111successful ticks/283bytes and Ninvaders109successful ticks/318bytes among10000attempts each. The documented finite duration/action quota is consistent with the approved bounded journal design; no unbounded timed-journal growth or repeated-hook hashing was found.

Mines generation cannot be reached through Chord on an unplaced board (native early no-op); first-reveal is correctly identified as Puzzle Reveal. Symbolic placement tracking models successful Mines flag/reveal/Solve history, native256history truncation and Undo/Redo/future branching. Each false-to-placed reveal is charged6M covering primary2M plus eight500k fallback deduction budgets; seven such generations fit, eight fail preflight. Invalid/wrong-family actions cannot silently advance this model to execute more generations because replay requires every operation to succeed and aborts immediately on failure/no-op. Terminal Mines generates its layout once at construction and has no first-reveal generation path. Solve implementations reveal/copy existing solutions/layouts and do not invoke puzzle generation or an unbounded search, so repeated Solve/Undo cannot regenerate boards. Jumble rotates existing Net tiles and has no constructor path. Native generators remain independently bounded and unchanged.
