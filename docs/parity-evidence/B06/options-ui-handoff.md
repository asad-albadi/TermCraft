## Behavior

All 36 supported stock presets are selectable from the core's typed menu; all 15 unsupported source variants appear disabled with a brief unavailable label. Custom controls expose supported Net dimensions, wrapping, barrier rate and uniqueness; Mines dimensions/count/no-guess request; Solo box sizes, diagonals, supported difficulty and all eight symmetries; Guess colours, pegs, guesses, blank and repetition rules; Map orientation, 30/75 regions and Easy/Normal; Untangle 4–25 points. Changes are pending until New game. The current game's configuration remains separately visible. A replacement session is constructed before modifying the current board, history, seed or selection; failed validation/generation leaves them intact. Bounded generation errors are translated into plain retry/change-settings advice.

Puzzle sessions expose typed configuration, redo, Solve and assisted state through the existing registry. Solve requires a separate reveal confirmation; Guess explicitly calls this giving up. Assistance is visible and follows undo/redo/reset. Terminal game controls retain their existing behavior. Actual configured rules drive player help; larger Solo digits use A–G for 10–16, Guess uses A for colour 10, and all values remain available as buttons. Pencil values up to bit16 are painted in individual mini-grid slots. Solo box boundaries and dashed X diagonals follow scene dimensions. Guess supports dynamic rows, peg selection/hold, distinct-colour and blank rules, quotas and revealed code. Net paints barrier-mask edges and opposite-edge continuation arrows. Mines displays explicitly revealed mines, including after death. Solo/Map easier starting boards and alternative layouts are disclosed in plain language.

The complete game surface scrolls in both directions, including toolbars and help on short windows; the board retains its own bounded scroll area. Minimum cell size is 24 points. Existing root/detached ownership, Close quarantine, background polling, terminal sessions, coalesced Untangle drag and emerald branding are retained.
