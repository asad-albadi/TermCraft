# B06 independent puzzle engines and selectable options

Evidence class: **RECOVERED historical primary-source correspondence**, not measured original behavior. These are independent Rust rules, generators and bounded typed scenes. No original executable, C engine, artwork, dependency, unsafe code, ambient I/O or external process is used by the component. This component does not complete B06 or establish native parity.

## Typed UI contract and common controls

Existing `PuzzleSession::new(PuzzleKind, seed)`, `new_map(seed, MapPreset)`, `input`/`apply`, `undo`, `reset`, `scene`, `outcome`, `kind`, `seed`, `can_undo`, plus `PuzzleKind::ALL`, `selector` and default `help` remain. New `new_config(seed, PuzzleConfig) -> Result<_, &'static str>` validates before allocation/generation; `configuration()` and session `help()` describe the selected rules. `PuzzleKind::presets()` supplies the exact historical stock definitions, including both conditional Map orientations and larger non-small-screen entries: **36 selectable and 15 explicitly disabled entries**. A disabled preset has `configuration: None` and an explanation; selecting it cannot silently substitute another game.

`redo()`/`can_redo()` restore undone states; only a changed branch discards redo, while invalid/no-op/highlight input preserves it. Combined undo/redo snapshots are bounded to 256. `solve() -> Result<bool, &'static str>` is explicit, deterministic and atomic/undoable, and restores the known generated answer (Guess instead gives up). Net also locks every solved tile, matching the source auxiliary-answer Solve; the same atomic snapshot restores the player’s earlier lock vector on undo and all solved locks on redo. `assisted()` follows the state through undo/redo and clears on reset. Mines Solve exposes a hidden layout only after explicit invocation, including after death. Reset restores the captured initial configuration/seed state, recentres Net highlight, and clears history, assistance and deaths. It does not regenerate another configuration.

`NetScene` adds wrapping and per-cell barrier masks (same N=1/E=2/S=4/W=8 representation as ports). `MinesScene` adds generation/solvable metadata and a layout `solution: Option<Vec<bool>>` that is `None` until explicit Solve. A UI can overlay correction marks on the preserved post-death cells using that layout. `SoloScene` adds box dimensions, diagonal/symmetry settings and the constructor logical certificate. Its pencil masks are now `u32`. Guess scene current/held/row pegs/terminal solution are vectors, retaining default lengths four and supporting Super length five. `MapScene` adds its typed configuration; generation/certificate remain exposed. These are source-compatible for dimension/iterator-based rendering, but fixed-array type annotations and fixed-size UI controls need adaptation.

Only typed scenes expose public board data. Net/Map/Solo/Untangle hidden answers remain internal; Guess reveals only at terminal outcome; Mines reveals its layout only on explicit Solve. Constructor certificates describe the initial puzzle, not a proof of arbitrary later user digits. Invalid public session input restores the full prior state and adds no history. All dimensions/counts have explicit caps; every search/generation/graph/flood/history path has a finite bound.

## Verification and retained gaps

The reviewed options round-0 handoff includes 48 component tests, whole-suite Linux verification, strict Clippy, formatting, Windows x86_64 MSVC and macOS aarch64 compile checks. FIX1 adds two public default/configured Net Solve-lock regressions (50 compiled tests total); its targeted checks cover Solve, Net and redo without repeating the broad 288-scene sampler. See the FIX1 report for actual amended-check results; see scoped `puzzle-options` evidence for actual final commands/results. Compilation does not establish native GUI execution or packaging. Eleven restored controlled mutations produce behavioral assertion failures across symmetry, logical grade, wrap/barriers/loop rules, redo, assistance, Guess blank/distinct rules, Mines corrections and point counts. Baseline default Solo rotational/logical failures and new Net fixed-fraction failures are separately captured. Tests sample eight seeds for each selectable stock setting and report actual fallback/exhaustion, rather than asserting all layouts match upstream.

**Still pending:** Solo Intermediate/Advanced/Extreme/Unreasonable, Killer cages and Jigsaw regions (including X variants); Map Hard/Unreasonable and arbitrary custom dimensions/region counts; custom Net dimensions 1/2 or over 16 and sub-percent probabilities; larger custom bounds outside those documented; source-complete Untangle graph generation; separate hint commands; original generator IDs, saved-game import/export and verified interoperability; configuration menus/dynamic controls/redo/Solve/correction rendering in native UI; native platform/package/original-runtime parity. The stock catalog explicitly disables unsupported source variants. This options component is an extension to the accepted restricted cores, **not full B06 completion**.
