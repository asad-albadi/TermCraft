- **Idle appearance:** a private D-Bus service implements the standard appearance `Settings.Read`. Changing its file from light to dark causes the production polling watcher to update System mode with no input. System screenshot mean RGB difference exceeds 100; explicit Light and Dark pairs are under 2 (normally exactly 0). The runner retains all six screenshots, observed mode, frame numbers and pixel differences. This verifies real D-Bus transport plus native rendered windows using a test portal; it does not qualify every distribution portal implementation.
- **Native clipboard:** a separate real eframe window owns the Unicode/multiline selection. Production `read_os_text` reads it (Wayland `wl-paste`, X11 arboard), and the existing multiline confirmation is clicked using native pointer input. Exact UTF-8 payload appears in the owned raw PTY. Production `Context::copy_text` then owns the native selection; a native paste event populates the peer's real TextEdit with exact matching bytes. Wayland uses an actual keyboard shortcut; X11 uses the backend's native `RequestPaste` after a keyboard-focus automation race. The native peer uses default fonts, so some screenshot glyphs are missing even though byte comparisons pass. No Unicode glyph-coverage claim is made.
- **Coordinates:** XTest drives the private X11 server; a small client of `zwlr_virtual_pointer_v1` drives the private Wayland seat, with a persistent test virtual keyboard providing real focus capability. Production-painted cell rectangles determine test injection positions, while independently expected SGR mouse bytes are captured by the real raw PTY. A real loopback RFB peer sends a 640×480 color frame and records production VNC pointer packets at quarter/three-quarter locations (one pixel tolerance for physical rounding). Detached views are actual native viewports. At 2×, the 1920×1080 output has only 960×540 logical space: the test chooses visible root cells and floats the desktop inside the output; it does not inject through clipped regions.
- **Backend proof:** Wayland launches with `DISPLAY` absent, Sway `xwayland disable`, and recorded `xdg_shell` native windows (`window: null`). X11 launches with `WAYLAND_DISPLAY` absent, uses private `DISPLAY=:71`, and observes genuine XTest/native-selection behavior. Every session records application environment and separate host/private network and X socket-directory identities. No fallback is accepted.
