# Routine implementation rulings within approved P01

- Retain exact signed native bytes rather than introducing patchelf transformations. Perl declares a RUNPATH rather than RPATH, so the launch-owned LD_LIBRARY_PATH overrides its installed module-library directory. The clean loader audit verifies every native object against the pinned directory; only glibc loader/libc/libm/libresolv remain OS dependencies.
- Include all pure Perl core modules/data from both core directories, together with IO/POSIX/Socket/Fcntl native modules and their library closure. The internal interpreter supports this audited Mosh wrapper, not arbitrary Perl applications. Keeping unrelated DB_File, compression and other XS extension APIs would enlarge the runtime and add unused native dependencies.
- Include OpenSSH's security-key and PKCS11 helper executables and libfido2/libcbor/libudev closure; set SSH_SK_HELPER and SSH_PKCS11_HELPER to owned private images. Hardware/provider devices and user-configured provider modules remain explicit user/OS integrations. Privileged hostbased ssh-keysign is not made setuid or silently replaced; that integration retains its configured OS helper requirement, with the explicit SystemMosh compatibility choice also available.
- Preserve the complete quoted SSH command tail. The existing connection API supplies `--ssh` followed by a shell-quoted command string, not `--ssh=/path`; only the authenticated first executable token is replaced with the private SSH path.
- Snapshot directories use /tmp explicitly so interpreter shebang length and Perl source quoting cannot be changed by TMPDIR containing spaces/quotes. The directory is mode 0700; verified files become 0500/0400 and survive until existing process-group teardown.
- Clean namespace SSH server runs as its own non-root fixture account. Its bootstrap uses upstream --no-ssh-pty because unprivileged user-namespace login accounting cannot chown the SSH PTY. Mosh's genuine server/client PTYs and encrypted UDP still execute. Host fixture also exercised default SSH PTY before this namespace-specific configuration.
- Remote fixture libutempter is independently downloaded/signed and recorded separately. It is not a client runtime dependency or a host-library bind. No host package, account, policy, route or interface is modified.
