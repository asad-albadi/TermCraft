The launcher accepts lowercase ASCII letters and digits, beginning with a letter, up to 32 bytes, and checks the ID against the installed layout catalogue. All 99 layout identifiers in the tested evdev catalogue meet that grammar. Actual symbol checks covered US and German. Variants, groups, themes, physical keyboard input, other host operating systems and comparison with the original application remain outside this qualification.
