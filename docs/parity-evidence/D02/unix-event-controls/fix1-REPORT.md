# D02 Unix serial controls FIX1

Both review findings are addressed in a private candidate. MAIN and the original review payload remain unchanged. The candidate preserves the original RXCHAR semantics, preserves the separate smartcard queue, and leaves the normal app build untouched.

1. Unix serial handles capture the six relevant unsigned Linux TIOCGICOUNT fields at successful logical CREATE, not when pinning the native mapping. GET_STATS emits six wrapping current-minus-baseline deltas. Missing baseline is STATUS_NOT_SUPPORTED even if a later driver read could succeed. Missing counters do not block CREATE. Non-Linux Unix continues to report stats as unsupported. The focused fixture overrides only the native counter boundary and tests all six fields, an unsigned wrap, missing baseline, and CLOSE/CREATE resetting the snapshot. Native PTYs exercise the unsupported path. Successful physical-driver calls remain unverified.
2. The common device channel keeps 16 ordinary credits and, only with mapped Unix serial devices, admits one additional supported, well-shaped SET_WAIT_MASK for a serial device ID. The worker still validates handle and authority. CLOSE can occupy a further position, so the bounded queue and result capacity are 18 with mapped Unix serial devices and 17 elsewhere. The real Channel test holds fifteen PTY reads and one WAIT, checks a normal getter, malformed and unmapped reset rejection at saturation, admits one reset and rejects a second before polling, and observes a success/zero WAIT and successful retry on the same handle. It saturates again, admits reset and CLOSE without draining, then checks all cancellations/completions and proves all ordinary credits work on reopen.

Focused Linux helper passed 7 tests, with 69 filtered. Full Linux helper passed 76 unit and 10 PCSC-worker tests, with none ignored. The reviewed candidate passed 74 + 10 and the original baseline had 69 + 10. The aarch64 Apple production-source native-component check passed. It typechecks serial, but excludes the Channel implementation and does not establish native execution. All test commands returned, and no processes from the helper or PCSC fixture remained in the process scan.
