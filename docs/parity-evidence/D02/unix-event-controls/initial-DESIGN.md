Unix serial controls will support RXCHAR from the bound tty input queue (FIONREAD), with an unread-byte watermark adjusted by reads through the owned descriptor. SET resets the watermark to the current queue. An already observed event stays latched until WAIT or a successful SET. The worker checks events before servicing reads. A pending wait is unique per handle; successful SET completes it with zero, close cancels it, and hangup reports disconnect. Mask changes require write access. Preserve existing read and write queue ordering. Other valid event bits return unsupported, reserved bits invalid. Linux GET_STATS maps the kernel TIOCGICOUNT counts only when the driver implements it. Other drivers and macOS decline stats. A status query that would need hardware error acknowledgment or unavailable hold flags, and a properties query requiring device capabilities, remain unsupported. No tty mutation for event observation. Scope is a single remote owner; queue sampling cannot see arrivals consumed between observations by other local tty readers.
