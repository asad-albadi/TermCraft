## Implemented delivery path

- Linux x86-64, Windows x64 and Apple Silicon macOS arm64 only. Version tags validate the application version; helper versions remain independent. Manual runs cannot publish.
- MIT LICENSE, privacy policy and credits ship with hashes on all existing formats. Debian includes full policy documentation; macOS has an unsigned installation and relocation guide. Component notices are independently regenerated from locked target graphs during candidate and download validation.
- Every release requires all three native regression lanes, actual relocated startup/RDP checks, two independently built increasing application versions, installed/relocated lifecycle and state preservation, plus Linux X11/native Wayland checks. A private lower baseline is not a previous public release. Fresh fixture credentials stay on private stdin; public artifacts contain hashes and observations rather than fixture data.
- Core tarball/DEB, Windows portable ZIP with per-user installer and macOS app ZIP remain supported formats. Linux adds a source-bound AppImage and complete corresponding-source/relink sidecar. Its measured runtime is built from pinned sources; ordinary client libraries have signed Ubuntu source/binary inventories. Host glibc and coherent graphics drivers remain external requirements. The historical AppImage fixture measured GLIBC 2.39; it does not prove older Debian compatibility or wider distro support.
- Aggregation revalidates downloaded bytes, complete file/link inventories, source, notices and native evidence. Publication uses one checksum inventory, the exact tracked-source archive and an isolated tag-only writer. Existing mismatched assets are never overwritten. Unsigned core is explicit; signing/notarization and optional runtime distribution enrollment remain separate gates.
