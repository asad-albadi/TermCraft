# MobaXterm feature-parity matrix

Full feature parity is the acceptance target; it has NOT been achieved.
See [PARITY_CHECKLIST.md](PARITY_CHECKLIST.md) for the prioritized gap inventory, evidence questions, and validation gates.
Last reviewed: 2026-11-25. Implemented means the named capability exists,
not that every original edge case has been reproduced. Partial means a usable
subset or external adapter. Missing means there is no equivalent engine.
Platform-specific identifies a platform adapter needing native validation.

## Verified evidence

Local tests exercise PTY command execution, terminal parsing, launch argument
preservation, store persistence, path handling and headless UI rendering.
Owned OpenSSH, FTP/FTPS, RDP, VNC, Telnet, HTTP and other protocol fixtures run
locally. Windows also has [native x64 evidence](docs/parity-evidence/execution/2026-11-25-windows-native.md)
for locked RDP helper tests, ConPTY, loopback XDMCP discovery, relocated package
startup and per-user installer smoke. Physical serial workflows, broader native
Windows/macOS runtime coverage and the original application runtime remain open.
See MECHANICS.md for decompilation evidence and estimated values.

These sources establish original feature scope and workflow expectations, not
proof that this replacement implements those features.

## Defaults and assumptions

Protocol ports use standards: SSH/SFTP 22, Telnet 23, Rsh 514, Rlogin 513,
RDP 3389, VNC 5900, FTP 21, Mosh UDP 60000 and XDMCP 177. Their equality with
all original profiles remains unverified. SSH keepalive 60 seconds is estimated.
Compression defaults on. X11 defaults off in this build: this differs from the
original documented checked workflow and requires a configured system display.
Existing saved options are preserved. SSH host-key policy and authentication
follow the user's installed OpenSSH configuration; passwords are not saved by default; eligible integrated prompts can use the opt-in encrypted vault.
SFTP pipeline 32 and 32 KiB request blocks derive from inspected original handlers;
the OpenSSH adapter does not reproduce separate original upload window tuning.
Serial defaults to 9600 baud, 8N1. Remote desktop size defaults to 1280x800.
HTTP defaults to localhost:8080 and one hour; SSH server to localhost:2222,
key-only. Desktop dimensions and service defaults are estimates.

## Completion criteria

Missing and partial rows remain release blockers for the requested full-parity
replacement. Each needs an implementation, native Windows/Linux/macOS tests,
protocol endpoint tests and comparison evidence before becoming implemented.

Workspace W01–W05 now includes configurable conflict-checked shortcuts, local history controls and distinct unread/error indicators. Headless GUI and real-PTY coverage is retained in `docs/parity-evidence/`; native window-manager and original behavior comparisons remain pending.

Saved-folder launches and per-session results, argument-safe shortcut generation, validated CLI actions and same-workspace local IPC have implementation checkpoints. Linux real-binary forwarding is tested; Windows/macOS native shortcuts, ACLs, IPC and original-app comparisons remain pending.

Game saves use the versioned TermCraft replay format. Overwrite confirmation is an app-owned modal with held-target identity checks and cooperative cancellation; it does not require Zenity. Native GTK Save/Load/Undo/Redo and invalid-file protection passed on the earlier packaged source; native overwrite on the revised final package remains pending. Original game save formats are not claimed compatible.
